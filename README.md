# منصة المتاجر — عدة متاجر في تطبيق واحد

كل متجر عزلة كاملة: منتجاته وطلبياته وأرصدته ورموز لوحته ورقم صاحبه بملفات منفصلة.

## الروابط
- `/` — دفتر المتاجر (القائمة + تسجيل متجر جديد برمز المنصة)
- `/s/<معرّف>` — واجهة متجر معين (الرابط الذي يُشارك للزبائن)

## التشغيل
- Build: `npm install`
- Start: `node server.js`

## الأسرار (من server.js أعلى الملف)
- MASTER_CODE — رمز تسجيل/إغلاق متجر من الدفتر
- DEFAULT_PIN — رمز لوحة كل متجر جديد (١٢٣٤) ويتغير من لوحة المتجر نفسها
- PHONE_SECRET — الرقم السري لخانة رقم صاحب الدكان
